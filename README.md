# .NET API Builder Guide

A static bilingual (Hungarian/English) learning site for building a modern ASP.NET Core REST API.

## Files
- `index.html` – page structure
- `styles.css` – responsive dark UI
- `app.js` – tabs, bilingual content, copy buttons and progress persistence

## Open locally
Double-click `index.html`, or run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Target stack in the guide
- .NET 10 / ASP.NET Core
- Entity Framework Core
- SQLite
- Controller-based REST API
- Built-in dependency injection
- Options pattern
- Repository + Service layers
- Customer → Order → OrderItem relationships
